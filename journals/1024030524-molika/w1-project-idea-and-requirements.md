# Week 1 : Project Idea, Requirement Analysis and Gantt Chart

## Work done

+  Took part in the team discussions on project ideas and agreed on
   TravelSync, a single platform for planning trips.
+  Discussed the problems travellers face today: information spread across
   many apps, no help in choosing a destination, and no easy way to plan
   with a group.
+  Started noting down the requirements the system would need to meet.
+  Started preparing the 15-week Gantt chart, dividing the project into
   phases: requirements, design, development, integration, testing and
   documentation.
