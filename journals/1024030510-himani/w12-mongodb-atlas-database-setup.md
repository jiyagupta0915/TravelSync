# Week 12 : MongoDB Atlas Database Setup

## Work done

+  Set up the TravelSync MongoDB database using MongoDB Atlas so the project could use a shared cloud-hosted database.
+  Configured the database connection for the backend through the MongoDB connection settings rather than relying only on a local database instance.
+  The backend uses the Motor asynchronous MongoDB driver to connect to the database and perform database operations from the FastAPI application.
+  Reviewed the database connection flow and how the application obtains access to the configured database.
+  This setup allowed team members working on the project to use the same database environment and made collaboration and integration easier.
