# Week 10 : Component Diagram and Health and Safety Feature

## Work done

+  Made the UML component diagram with help from my teammates (web
   frontend, backend API, recommendation and health insights, group chat
   server, database and external services).
+  Started building the Travel Health and Safety feature and pushed the
   first version:
   +  a backend health engine that finds seasonal outbreak patterns by
      month, flags unusual periods and outbreaks with Isolation Forest,
      and groups states with similar patterns using K-Means;
   +  a curated list of current health alerts;
   +  an API endpoint that returns this information for a destination;
   +  a Health and Safety page in the frontend, with a link from the Home
      page and the sidebar.
