# Week 7 : UML Collaboration Diagram

## Work done

+  Created the UML collaboration diagram, also known as a communication diagram, for the TravelSync project.
+  Identified the objects participating in the selected system interaction and represented the links between those objects.
+  Showed the messages exchanged between the participating objects and used message numbering to communicate the order of interaction.
+  The diagram helped explain how different parts of the system cooperate to complete an operation rather than showing each object in isolation.
+  Reviewed the diagram for clear object relationships, message labels and a readable interaction sequence.
